# ASAPTools — Design System

## Design Goal

ASAPTools should feel like a modern, premium technology product.

The interface should communicate:

- Speed
- Simplicity
- Reliability
- Useful technology
- Clean engineering

The website should feel polished enough to be a real commercial SaaS product.

It should NOT look like a generic "free online tools" website.

---

## Core Design Principle

The user should understand what a tool does within seconds.

The interface should answer:

1. What can I do here?
2. Where do I start?
3. What happens after I start?
4. How do I get my result?

Avoid unnecessary steps and visual clutter.

---

## Brand Personality

ASAPTools should feel:

- Modern
- Fast
- Confident
- Technical
- Friendly
- Minimal
- Practical

It should not feel:

- Corporate
- Overly formal
- Childish
- Cheap
- Spammy
- Overly futuristic
- Over-designed

---

## Logo

The ASAPTools logo should work in multiple contexts:

- Full website header
- Mobile header
- Favicon
- GitHub avatar
- Social profile
- Open Graph image
- App icon

The icon should remain recognizable without the wordmark.

Avoid generic symbols such as:

- Toolbox
- Wrench
- Robot
- Generic lightning bolt
- Generic globe
- Random AI brain

The final logo and brand assets will be documented here once the branding is finalized.

---
